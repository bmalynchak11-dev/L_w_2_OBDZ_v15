# Словник даних проєкту (FinTrecker / Financial DB)

## 1. Таблиця `user`
Опис: Користувачі фінансової системи.

| Стовпець | Тип | Nullable | Identity | Опис |
| :--- | :--- | :--- | :--- | :--- |
| `id` | integer | Ні | Так | Первинний сурогатний ключ користувача |
| `email` | text | Ні | Ні | Унікальна електронна пошта |
| `username` | text | Ні | Ні | Нікнейм / ім'я користувача |
| `created_at` | timestamptz | Ні | Ні | Дата та час створення облікового запису |

## 2. Таблиця `category`
Опис: Категорії доходів та витрат.

| Стовпець | Тип | Nullable | Identity | Опис |
| :--- | :--- | :--- | :--- | :--- |
| `id` | integer | Ні | Так | Первинний ключ категорії |
| `name` | text | Ні | Ні | Назва категорії витрат/доходів |
| `type` | text | Ні | Ні | Тип категорії ('income' або 'expense') |
| `created_at` | timestamptz | Ні | Ні | Час реєстрації категорії |

## 3. Таблиця `wallet`
Опис: Рахунки та платіжні гаманці користувача.

| Стовпець | Тип | Nullable | Identity | Опис |
| :--- | :--- | :--- | :--- | :--- |
| `id` | integer | Ні | Так | Первинний ключ гаманця |
| `user_id` | integer | Ні | Ні | Власник рахунку (FK на user) |
| `name` | text | Ні | Ні | Назва гаманця (картка, готівка тощо) |
| `balance` | numeric(12, 2) | Ні | Ні | Поточний баланс (>= 0.00) |
| `currency` | text | Ні | Ні | Валюта рахунку (за замовчуванням 'UAH') |

## 4. Таблиця `budget`
Опис: Встановлені місячні бюджетні ліміти за категоріями.

| Стовпець | Тип | Nullable | Identity | Опис |
| :--- | :--- | :--- | :--- | :--- |
| `id` | integer | Ні | Так | Первинний ключ ліміту |
| `user_id` | integer | Ні | Ні | Користувач, для якого діє ліміт (FK на user) |
| `category_id` | integer | Ні | Ні | Категорія витрат (FK на category) |
| `limit_amount` | numeric(12, 2) | Ні | Ні | Сума ліміту (> 0.00) |
| `month` | date | Ні | Ні | Місяць, на який виділено бюджет |

## 5. Таблиця `transaction`
Опис: Фінансові операції (витрати/доходи).

| Стовпець | Тип | Nullable | Identity | Опис |
| :--- | :--- | :--- | :--- | :--- |
| `id` | integer | Ні | Так | Первинний ключ транзакції |
| `wallet_id` | integer | Ні | Ні | Гаманець списання/зарахування (FK на wallet) |
| `category_id` | integer | Ні | Ні | Категорія транзакції (FK на category) |
| `amount` | numeric(12, 2) | Ні | Ні | Сума платежу (<> 0.00) |
| `transaction_date`| date | Ні | Ні | Дата здійснення платежу |
| `description` | text | Так | Ні | Необов'язковий текстовий коментар |

## 6. Таблиця `audit_log`
Опис: Журнал подій та дій користувачів у системі.

| Стовпець | Тип | Nullable | Identity | Опис |
| :--- | :--- | :--- | :--- | :--- |
| `id` | integer | Ні | Так | Первинний ключ запису журналу |
| `user_id` | integer | Так | Ні | Користувач, який виконав дію (FK на user) |
| `action` | text | Ні | Ні | Назва системної дії |
| `created_at` | timestamptz | Ні | Ні | Час фіксації події в системі |
