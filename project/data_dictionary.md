# Словник даних проєкту

## Таблиця user
Опис: Користувачі системи.

| Стовпець | Тип | Nullable | Identity | Опис |
| :--- | :--- | :--- | :--- | :--- |
| id | integer | Ні | Так | Первинний сурогатний ключ |
| email | text | Ні | Ні | Унікальна електронна пошта |
| username | text | Ні | Ні | Ім'я або нікнейм користувача |
| created_at | timestamptz | Ні | Ні | Час реєстрації користувача |

## Таблиця category
Опис: Категорії фінансових доходів та витрат.

| Стовпець | Тип | Nullable | Identity | Опис |
| :--- | :--- | :--- | :--- | :--- |
| id | integer | Ні | Так | Первинний ключ категорії |
| name | text | Ні | Ні | Назва категорії |
| type | text | Ні | Ні | Тип категорії (income або expense) |
| created_at | timestamptz | Ні | Ні | Час створення категорії |

## Таблиця wallet
Опис: Рахунки та гаманці користувачів.

| Стовпець | Тип | Nullable | Identity | Опис |
| :--- | :--- | :--- | :--- | :--- |
| id | integer | Ні | Так | Первинний ключ рахунку |
| user_id | integer | Ні | Ні | Власник рахунку (FK на user) |
| name | text | Ні | Ні | Найменування рахунку |
| balance | numeric(12, 2) | Ні | Ні | Баланс коштів |
| currency | text | Ні | Ні | Валюта рахунку |

## Таблиця budget
Опис: Бюджетні обмеження за категоріями на місяць.

| Стовпець | Тип | Nullable | Identity | Опис |
| :--- | :--- | :--- | :--- | :--- |
| id | integer | Ні | Так | Первинний ключ бюджету |
| user_id | integer | Ні | Ні | Користувач (FK на user) |
| category_id | integer | Ні | Ні | Категорія (FK на category) |
| limit_amount | numeric(12, 2) | Ні | Ні | Максимальна сума ліміту |
| month | date | Ні | Ні | Розрахунковий місяць |

## Таблиця transaction
Опис: Операції доходів і витрат.

| Стовпець | Тип | Nullable | Identity | Опис |
| :--- | :--- | :--- | :--- | :--- |
| id | integer | Ні | Так | Первинний ключ операції |
| wallet_id | integer | Ні | Ні | Рахунок платежу (FK на wallet) |
| category_id | integer | Ні | Ні | Категорія витрати/доходу (FK на category) |
| amount | numeric(12, 2) | Ні | Ні | Сума фінансової транзакції |
| transaction_date | date | Ні | Ні | Дата виконання платежу |
| description | text | Так | Ні | Опис призначення платежу |
